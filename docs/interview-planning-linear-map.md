# Interview-planning Linear index

[Open the Linear project](https://linear.app/aliwonderland/project/job-search-os-interview-planning-vertical-slice-3044c395c70e) for task acceptance criteria, dependencies, status, milestones, and verification evidence.

The [repository contract](interview-planning-spec.md) owns product behavior, shared safeguards, scope, and acceptance scenarios T1–T8. Maintain task-specific requirements in Linear rather than copying tickets into this repository.

## Planning identifiers

The contract uses stable identifiers recorded in each Linear ticket's description:

| Area                            | Planning IDs | Linear issues |
| ------------------------------- | ------------ | ------------- |
| Foundation fixtures and actions | F1–F3        | ALI-5–ALI-7   |
| Interview intake                | I1–I5        | ALI-8–ALI-12  |
| Research brief                  | B1–B3        | ALI-13–ALI-15 |
| Planning                        | P1–P5        | ALI-16–ALI-20 |
| Approval and recovery           | A1–A8        | ALI-21–ALI-28 |
| Home and practice               | H1–H3        | ALI-29–ALI-31 |
| Debrief                         | D1–D5        | ALI-32–ALI-36 |

M0 development foundation is tracked separately in ALI-37–ALI-42. Its database and startup checks do not satisfy T1–T8.
